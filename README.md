# MAU Properties LLC

Informational company site connecting real estate with the digital ventures Hankins.work and SickDocs. Buildless HTML/CSS/JS with self-hosted Newsreader and Manrope fonts. Font licenses are included in assets/.

GitHub Pages provides a preview. Production is intended for the owner's Proxmox hosting through Cloudflare, subject to domain authorization. No property listings, business contact details, performance statistics, pricing, or availability are invented. No forms, analytics, or medical record handling are included.

Preview with any static HTTP server. No build step is required.
